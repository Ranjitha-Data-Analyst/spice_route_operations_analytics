Weekly Operations Review

This folder contains the weekly operations review report for the Spice Route Kitchens analytics project.

Project Highlights

* Analyzed operational data across 20 restaurant outlets.
* Evaluated checklist completion and compliance performance.
* Reviewed ticket status, priority, and recurring operational issues.
* Identified underperforming outlets and recommended corrective actions.

Key Findings

* Average compliance: 82.71%
* Missing daily checklist submissions: 921
* Daily checklist completion rate: 74.70%
* Total tickets: 304
* High-priority tickets: 62
